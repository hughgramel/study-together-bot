# Features Documentation

This directory contains detailed documentation for specific features of the Study Together bot.

## Structure

- `findgroups/` - Documentation for the find groups feature
  - `FINDGROUPS_CODE.md` - Technical implementation details
  - `FINDGROUPS_SUMMARY.md` - Feature overview and user guide
  - `FINDGROUPS_VERIFICATION.md` - Testing and verification procedures

## Adding New Features

When implementing new features, create a subdirectory with:
1. Implementation/code documentation
2. User-facing summary or guide
3. Testing and verification procedures

See the existing `findgroups/` directory as an example structure.
